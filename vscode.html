VS Code에서 Claude Code 쓰기 — 사전 필수 준비

커리큘럼Day 1 Webhook 안내VS Code 준비

11월 04일(수) Claude Code 수업 전까지 끝내 주세요. 약 30분이면 됩니다(파이썬이 이미 있으면 20분). Claude Code 설치·로그인을 끝낸 상태를 전제로 합니다. 커리큘럼으로 돌아가기

수업에서는 VS Code 화면 하나에 왼쪽 파일 목록과 아래쪽 터미널을 띄워 두고, 그 터미널에서 claude 를 실행합니다. Claude Code가 만든 파일이 왼쪽에 바로 나타나기 때문에, 무엇이 생기고 바뀌었는지 눈으로 확인하면서 따라올 수 있습니다.

한눈에 보는 체크리스트

# 할 일 시간 완료 확인
1 VS Code 설치 5분 VS Code가 열린다
2 작업 폴더를 VS Code로 열기 2분 왼쪽에 STA3\<이름> 폴더의 파일이 보인다
3 VS Code 안에서 터미널 열기 2분 Windows는 PS C:\STA3\<이름>> · Mac은 ~/STA3/<이름> 이 보인다
4 터미널에서 claude 실행 확인 5분 claude --version 결과에 버전 숫자가 나온다
5 로그인 계정 확인 2분 /status 결과가 Team 조직이다
6 화면 설정 2가지 3분 자동 저장 켜짐 · 터미널 글씨가 잘 보인다

1. VS Code 설치 (5분)

https://code.visualstudio.com → 「Download」

Windows Mac
받을 파일 User Installer (x64) Mac Universal (zip)
설치 받은 파일 실행 → 기본값으로 「다음」 zip을 풀면 생기는 Visual Studio Code 앱을 응용 프로그램(Applications) 폴더로 끌어다 놓기
설치 중 체크 「PATH에 추가」 켠 상태 그대로 · 「Code(으)로 열기」 작업 두 개도 켜 두면 편합니다 —
첫 실행 시작 메뉴 → 「Visual Studio Code」 응용 프로그램 폴더에서 실행 → 「인터넷에서 다운로드한 앱입니다」 창 → 열기
  • Mac은 다운로드 폴더에서 바로 실행하지 마세요. 업데이트와 권한이 꼬입니다
  • 한국어 화면이 좋으면 오른쪽 아래 「언어 팩 설치」 알림 → 설치 → 다시 시작 (선택)

Mac만 추가로 — ⌘ + Shift + P → shell command 입력 → 「Shell Command: Install 'code' command in PATH」 클릭 (터미널에서 code . 로 현재 폴더를 VS Code로 열 수 있게 됩니다)

2. 작업 폴더를 VS Code로 열기 (2분)

  1. 메뉴 「파일(File) → 폴더 열기(Open Folder)」
  2. 작업 폴더 선택 - Windows C:\STA3\<이름>\ · Mac ~/STA3/<이름>/
  3. 「이 폴더에 있는 파일의 작성자를 신뢰합니까?」 → 「예, 작성자를 신뢰합니다」
  4. 완료 확인 — 왼쪽 탐색기에 SEILOneCompany_Sales데이터.xlsx 와 해커톤 .twbx 가 보인다

매 수업 시작할 때 이 폴더를 먼저 열고 시작합니다. 다른 폴더(바탕화면·다운로드)를 연 채로 Claude Code를 실행하면 엉뚱한 곳에 파일이 생깁니다.

3. VS Code 안에서 터미널 열기 (2분)

  • 메뉴 「터미널(Terminal) → 새 터미널(New Terminal)」 또는 단축키 Ctrl + ` (Mac도 ⌘가 아니라 Ctrl)
  • 아래쪽에 터미널 창이 열립니다. 맨 앞 글자를 확인하세요
이렇게 보이면 정상 다르게 보이면
Windows PS C:\STA3\gildong> 앞에 PS 가 없다(명령 프롬프트) → 터미널 창 오른쪽 위 + 옆 ˅ → PowerShell 선택
Mac gildong@MacBook gildong % bash-3.2$ 처럼 나온다 → 그대로 써도 되지만 ˅ → zsh 선택 권장
  • 경로가 작업 폴더가 아니면 2번(폴더 열기)을 다시 합니다

4. 터미널에서 claude 실행 확인 (5분)

VS Code 터미널에 입력합니다.

claude --version
  • 버전 숫자가 나오면 성공
  • 「claude 을(를) 찾을 수 없습니다」 / command not found: claude 가 나오면 1. VS Code를 완전히 종료했다가 다시 엽니다 (Windows는 창 닫기, Mac은 ⌘ + Q) — Claude Code를 VS Code보다 나중에 설치하면, 이미 열려 있던 VS Code는 새 설치를 모릅니다. 가장 흔한 원인입니다 2. 그래도 안 되면 Claude Code 설치 명령(Windows irm https://claude.ai/install.ps1 | iex · Mac curl -fsSL https://claude.ai/install.sh | bash)을 VS Code 터미널에서 한 번 더 실행 → VS Code 다시 종료·실행 3. 그래도 안 되면 화면을 캡처해 두세요. 수업 시작 전에 도와드립니다

5. 로그인 계정 확인 (2분)

claude
  1. 처음이면 「이 폴더를 신뢰합니까?」 → Yes
  2. 로그인을 묻으면 「Claude account with subscription」 → 브라우저에서 Team 조직 선택 → 허용
  3. Claude Code 안에서 /status 입력 → 로그인 계정이 Team 조직인지 확인 - 개인 Pro·무료 계정이면 /logout → claude 다시 실행 → Team 조직으로 로그인
  4. 나갈 때는 /exit (또는 Ctrl + C 두 번)

6. 화면 설정 2가지 (3분)

  1. 자동 저장 켜기 — 메뉴 「파일(File) → 자동 저장(Auto Save)」에 체크 - Claude Code가 고친 파일과 내가 VS Code에서 고친 파일이 엇갈리지 않게 합니다
  2. 터미널 글씨 키우기 — 설정(Windows Ctrl + , · Mac ⌘ + ,) → 검색창에 terminal font size → 16 정도 - 에디터 글씨(editor font size)와 따로 설정해야 합니다. Claude Code는 터미널에서 돌기 때문에 터미널 글씨가 더 중요합니다

7. 시험 질문 1개 (2분)

VS Code 터미널에서 claude 를 실행하고 아래처럼 물어봅니다.

이 폴더에 어떤 파일이 있는지 알려줘
  • 엑셀·twbx 파일 이름이 답에 나오면 준비 완료입니다
  • 엉뚱한 폴더 파일이 나오면 → 2번(폴더 열기)부터 다시
  • 확인했으면 /exit 로 나옵니다. 8번은 Claude Code 밖, 그냥 터미널에서 합니다

8. 파이썬 + 엑셀 패키지 (10분)

11월 04일 실습에서 Claude Code가 엑셀을 읽어 집계할 때 파이썬과 pandas·openpyxl 을 씁니다. Windows는 python, Mac은 python3 입니다. 이 차이만 기억하면 나머지는 같습니다.

8-1. 이미 있는지 먼저 확인

Windows Mac
python --version python3 --version
  • Python 3.10 이상의 버전 숫자가 나오면 → 8-3으로 건너뜁니다
  • 숫자가 안 나오면 → 8-2로

8-2. 설치

Windows

  1. VS Code 터미널에 입력 → Enter powershell winget install Python.Python.3.12 - 「이 앱이 디바이스를 변경하도록 허용하시겠어요?」 → 예
  2. VS Code를 완전히 종료했다가 다시 실행 (꼭 필요) → python --version 다시 확인
  3. winget 이 안 되면 → https://www.python.org/downloads → 「Download Python 3.x」 → 설치 첫 화면에서 「Add python.exe to PATH」 반드시 체크 → Install Now → VS Code 다시 실행

python 을 쳤는데 Microsoft Store가 열리면 파이썬이 없는 것입니다. Store에서 설치하지 말고 위 1번으로 설치하세요.

Mac

  1. python3 --version 을 쳤을 때 「명령어 라인 개발자 도구를 설치하겠습니까?」 창이 뜨면 → 설치 (5~10분) → 끝나면 python3 --version 다시 확인
  2. 창이 안 뜨고 오류만 나오면 → https://www.python.org/downloads → 「Download Python 3.x」 → 받은 .pkg 실행 → 기본값으로 설치 → VS Code ⌘ + Q 로 종료 후 다시 실행

8-3. 엑셀 패키지 설치

Windows Mac
python -m pip install pandas openpyxl python3 -m pip install pandas openpyxl

설치가 끝나면 확인합니다.

Windows Mac
python -c "import pandas, openpyxl; print('pandas OK')" python3 -c "import pandas, openpyxl; print('pandas OK')"
  • pandas OK 가 나오면 준비 끝입니다
  • Mac에서 externally-managed-environment 오류가 나오면 → 캡처만 해 두세요. 수업에서 Claude Code로 같이 해결합니다
  • 회사 PC라 pip 가 인증서·프록시 오류로 막히면 → 캡처해 두세요. 집 PC로 오시거나 수업 시작 전에 도와드립니다

VS Code 확장에서 「Python」(게시자 Microsoft) 을 설치하라는 알림이 뜨면 설치해도 됩니다(선택). 확장만으로는 파이썬 본체가 설치되지 않으니 위 8-2는 따로 해야 합니다.

선택 — Claude Code 확장 프로그램

VS Code 왼쪽 「확장(Extensions)」(Ctrl + Shift + X · Mac ⌘ + Shift + X)에서 「Claude Code」(게시자 Anthropic) 를 설치해 두면, Claude가 고친 내용을 VS Code의 비교 화면으로 볼 수 있습니다. 수업은 터미널로 진행하므로 필수는 아닙니다. 설치한다면 게시자가 Anthropic 인지 꼭 확인하세요 — 이름이 비슷한 다른 확장이 많습니다.

막혔을 때

증상 원인 해결
claude 를 찾을 수 없다 VS Code가 설치 전에 열려 있었다 VS Code 완전히 종료 후 다시 실행
Windows 터미널에 PS 가 없다 기본 터미널이 명령 프롬프트 3번 표대로 PowerShell 선택
Windows에서 「이 시스템에서 스크립트를 실행할 수 없으므로…」 PowerShell 실행 정책 화면을 캡처해 두세요. 수업 시작 전에 같이 바꿉니다
Mac에서 「"터미널"(또는 "Code")이 폴더에 접근하려고 합니다」 macOS 권한 확인 허용. 거부했다면 「시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더」에서 켜기
/status 가 개인 계정 다른 계정으로 로그인 /logout 후 Team 조직으로 다시 로그인
파이썬을 설치했는데 python 을 못 찾는다 VS Code가 설치 전에 열려 있었다 VS Code 완전히 종료 후 다시 실행
Mac에서 python: command not found Mac은 이름이 다르다 python3 로 입력
엑셀 한글이 깨져 보인다 (Windows) 콘솔 인코딩 python -X utf8 ... 으로 실행
회사 PC라 VS Code 설치가 막힌다 회사 보안 정책 터미널(PowerShell·Mac 터미널)만으로도 수업은 됩니다. 파일은 탐색기·Finder로 확인

하지 말 것

  • ❌ 바탕화면·다운로드 폴더를 연 채로 claude 실행 — 항상 작업 폴더를 먼저 연다
  • ❌ 게시자가 Anthropic이 아닌 「Claude」 확장 설치
  • ❌ Claude Code에 개인 계정으로 로그인
  • ❌ 터미널 화면 캡처를 올릴 때 토큰·Webhook 주소·비밀번호가 보이는 채로 공유
